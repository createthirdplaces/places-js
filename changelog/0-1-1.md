
## Enhancments

- Add option to configure store set in PresentationComponent connectedCallback
  method in subclass constructor.
- Add option for data store signals to use a custom data selector.
- Add option to define component as root for template.
- Add option for wating for the results of a pending data store fetch when a
  second fetch is attempted.
- Filter out extra whitespace when processing component template.
- Make sure data store is automatically subscribed to updates when store updates
  are setup through DataStore.createWithDataStoreSignals.
- Make sure component is automatically rendered when subscring to store.
- Make sure template strings for non-reactive fields are automatically
  proccessed for single item templates.
- Optimize performance for rendering and updating list of items in a compnent.
- Remove requirement to specify fields for a data store signal configuration.
- Support for initial synchronous rendering with empty state.
- Support partial updates for single item templates.
- Support for setting CSS display and visibiliy attributes throguh template.
- Update DataStore.js to add function for external subscribers.

## External integration.

- Create copy of store data when publishing to external store to prevent
  unwanted data modifications.

## Bugfixes

- Fix bug where signle item template is sometimes added to wrong component when
  there are multiple templates.
- Fix bugs with tracking state updates.
- Fix bug with store signal selectors making invalid changes to store.
- Fix bug with presentation component making an unecessary change to a DOM node
  variable that was causing rendering issues.
- Fix change detection for list of items displayed in component when items are moved.
- Make sure that presentation component event handler accounts for target being
  removed from DOM by event heandler from nested web component.
